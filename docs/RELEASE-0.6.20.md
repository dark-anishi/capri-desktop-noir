# Capri Desktop NOIR 0.6.20

Убрано ожидание полного завершения загрузки страницы из команд встроенного плеера. Вместо `webContents.executeJavaScript`, который ждёт `did-stop-loading`, используется `mainFrame.executeJavaScript` для уже готового DOM. Громкость не требует `userGesture`; жест сохраняется для команд воспроизведения.

Команда и чтение состояния имеют предел ожидания 2,5 секунды. При ошибке Promise завершается, поэтому быстрое меню снимает состояние занятости. Просроченный код проверяет срок перед выполнением и не применяет старое значение громкости после позднего восстановления страницы. Готовность сбрасывается при навигации и устанавливается на `dom-ready`.

Проверки в изолированном Electron: воспроизведение старого ожидания `did-stop-loading`, быстрая команда на скрытой вкладке при продолжающейся загрузке, зависший ответ, предел ожидания и отказ от просроченной команды. Предыдущие проверки синхронизации, нелинейной шкалы, значений 25%/7%/0%/100% и перезагрузки проходят. Проверка адаптера публичной страницы Яндекса также проходит. Авторизованное воспроизведение и реальный сетевой тайм-аут пользователя отдельно не воспроизводились.

Источник поведения обёртки Electron: [web-contents.ts для 44.9.3](https://github.com/electron/electron/blob/v44.9.3/lib/browser/api/web-contents.ts).
