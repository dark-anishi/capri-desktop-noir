# Capri 0.6.8

- Ручное «Подремать» сохраняет лежачую позу и Zzz при движении курсора. «Проснуться», клик по персонажу и важное уведомление будят её.
- Реплики сидящей Capri размещаются сбоку. Интро и эффекты используют палитру выбранного скина.
- При посадке и смене активного окна Capri восстанавливает верхний слой без перехвата фокуса. Собственные меню Capri исключены из списка перекрывающих окон; настоящее перекрытие края другим приложением сохраняет прежнее поведение.
- Значки приложений можно переставлять перетаскиванием. Порядок сохраняется; недавние приложения продолжают сортироваться по времени запуска.
- Во вкладку «Папки» можно перетаскивать каталоги и ярлыки каталогов. Хранятся ссылки: исходные папки, их содержимое и ярлыки остаются на своих местах. Правый клик → «Убрать из меню» удаляет только ссылку Capri.

## Zapret

Нажми колесо по Capri → «Запустить Zapret». При первом использовании выбери распакованную папку Zapret, затем стратегию в «Стратегии Zapret». Следующий запуск использует последний успешно запущенный `general*.bat`. Если папка исчезла, Capri снова предлагает выбрать её. Смена папки доступна после остановки.

Electron работает без повышения прав; Windows запрашивает UAC только для отдельного вспомогательного процесса. Компоненты выбранной локальной папки проверяются по хешам и блокируются от изменения на время работы. Внешние стратегии не скачиваются. Capri завершает только созданное ею дерево процессов через Windows Job Object, в том числе при закрытии приложения или потере управляющего процесса. Отдельные службы Zapret не устанавливаются и не удаляются. Совместимость с чужой уже работающей копией Zapret не гарантируется; о преждевременном завершении стратегии выводится ошибка.

Проверены менеджер и меню на изолированных фикстурах, а также запуск безвредного batch с дочерними процессами и их завершение настоящим Windows Job Object. Реальные стратегии пользователя, драйвер WinDivert, UAC и сетевой обход в этих тестах не запускались.

## Вопросы Codex

Существующий хук Capri распознаёт `request_user_input` и `request_user_input_async` через `PreToolUse`/`PostToolUse`: показывает вопрос, варианты и отдельную реплику. Фоновая работа и окончание другой операции не закрывают ожидающий вопрос. Ответ закрывает уведомление; асинхронный ответ, доставленный следующим пользовательским сообщением, также завершает ожидание.

Установи обновление и включи/разреши хуки Capri в Codex, если они ещё не были включены. При необходимости открой новый чат после настройки. Отдельное несуществующее событие Notification в конфигурацию Codex не добавляется. Вопросы, написанные только обычным текстом без инструмента запроса ввода, этим механизмом не определяются. Основано на [официальных событиях и покрытии инструментов Codex](https://learn.chatgpt.com/docs/hooks#tool-coverage).
