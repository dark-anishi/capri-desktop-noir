# Capri Desktop NOIR 0.6.19

Исправлен конфликт двух способов установки громкости: при доступном ползунке Яндекс Музыки Capri больше не записывает такое же число напрямую в `HTMLMediaElement.volume`. Плеер самостоятельно преобразует шкалу интерфейса в аудиоуровень. Прямое управление аудио сохранено как запасной путь, когда штатного ползунка нет. То же правило применяется при play/playing, чтобы начало трека не сбрасывало громкость.

В изолированном Electron тест с нелинейной шкалой воспроизвёл на старом коде скачок 27% → 52%. После исправления проходят двусторонняя синхронизация, стабильные 25% и 7% при повторных чтениях и событии playing, границы 0/100% и перезагрузка. На настоящей публичной странице Яндекса проверено сохранение значения после mute/unmute. Тесты не используют пользовательский аккаунт и не проигрывают треки.
