## Сборка и проверка

На Windows x64 с Node.js 20+ и компилятором .NET Framework:

```powershell
npm ci
npm run vpn:prepare
npm test
npm run dist
```

Подготовка обязательна перед тестами на чистом checkout. `npm run dist` повторно вызывает `vpn:prepare` через `predist` и создаёт `dist/Capri-Setup-0.6.15.exe`.

Тесты Electron и нативного протокола в `tools/` запускаются отдельно от `npm test`; некоторые требуют Playwright, собранных Windows-компонентов или подготовленной среды. Наличие теста не означает, что требующий UAC или реальной сети сценарий выполнен. Не используй личную подписку и действующий VPN как неявную тестовую среду.

При сообщении об ошибке укажи версию, Windows и шаги воспроизведения. Приложи обезличенный скриншот или короткое сообщение об ошибке. Не прикладывай папку данных, полный профиль, ссылку подписки, ключи или токены.
