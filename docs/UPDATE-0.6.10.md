# Capri 0.6.10

- Меню на колесо подстраивает высоту под содержимое. Пустого хвоста снизу нет; раскрытые списки увеличивают окно в пределах рабочей области экрана. Общая область не прокручивается.
- Вывод ошибок/«консоль» Zapret из меню удалён. Управление VPN, Zapret, музыкой и персонажем остаётся независимым.
- Исправлено зависание «Zapret — подожди…» с последующим завершением работающего движка. Синхронный Windows pipe блокировал отправку подтверждения запуска, пока другой поток ожидал остановку. Асинхронный канал допускает обе операции одновременно. После подтверждения таймер запуска отменяется; остановка по кнопке и завершение принадлежащего Capri дерева при закрытии приложения сохранены.
- При выборе другой локации VPN открытые TCP/UDP-соединения автоматически переподключаются через новый сервер. Новая служба использует документированный `DELETE /connections`; прежняя установленная служба, не поддерживающая эту операцию, автоматически перезапускает ядро с уже сохранённым выбором. Ручное выключение и включение не требуется. Повторный выбор той же локации не обрывает соединения.

Переподключение означает краткий разрыв текущих сетевых сессий: приложения создают их заново через выбранный сервер. Это относится к соединениям управляемого ядра Capri, не к процессам сторонних VPN.

## Проверка

- `npm test` — 58 проверок, включая новый сценарий с настоящим Mihomo и потоковым CONNECT-туннелем: до исправления старый туннель оставался открытым после выбора B, после исправления он автоматически закрывается, новое соединение идёт через B без перезапуска ядра.
- Старый протокол службы проверен отдельным тестом: сохранение выбора предшествует автоматическому переподключению; повторный выбор не перезапускает ядро. Это имитация старой службы, не системный TUN-тест.
- `tools/test-zapret-protocol.cjs` — настоящий протокол Node → native broker → защищённый pipe → native host → безопасный batch без UAC. До исправления движок работал, а подтверждение блокировалось; после исправления подтверждение приходит, процесс остаётся жив после тестового таймаута запуска. Проверены остановка и очистка после падения broker.
- `tools/test-quick-menu-layout-ui.cjs` — настоящий Electron: компактная высота, раскрытие/сворачивание списков, отсутствие общей прокрутки, пустого хвоста и встроенного вывода ошибок.
- Настоящий сетевой Zapret, запрос UAC и переключение системного TUN пользователя в этой проверке не выполнялись; действующее соединение пользователя не изменялось.

Использован документированный [API соединений Mihomo](https://wiki.metacubex.one/en/api/#connections).
