# Capri Desktop NOIR 0.6.11

Capri для Windows 10/11 x64: чёрно-белый персонаж, библиотека приложений и папок, встроенная Яндекс Музыка и собственный VPN-интерфейс на Mihomo.

- Компактное меню на колёсико подстраивается под содержимое без пустого поля снизу. VPN, Zapret, музыка, закрепление и сон управляются независимо.
- Приложения можно переставлять, распределять по категориям и запускать из истории. Папки хранятся отдельными ссылками без переноса исходных данных.
- NOIR и ORIGINAL, сидячие позы, сон лёжа с Zzz и реакции на музыку и вопросы Codex.
- YAML/HTTPS-подписки, избранные серверы, трафик, DNS, прямые исключения сайтов и системный TUN через Windows-службу. Смена локации переподключает старые соединения ядра.
- Запуск локальных стратегий Zapret с сохранением последней успешной; исправлен обмен подтверждением запуска между нативными компонентами.

## Установка

Скачай `Capri-Setup-0.6.11.exe`; контрольная сумма публикуется в `SHA256SUMS.txt`. Установщик без цифровой подписи. Node.js для готовой сборки не нужен. Clash Verge Rev отдельно не требуется; локальная копия Zapret в комплект не входит.

## Границы проверки

Установка/обновление TUN-службы и привилегированный запуск Zapret требуют ручного подтверждения UAC. Electron работает без повышения прав. Полная системная матрица TUN — маршруты, DNS-утечки, смена сети, сон и аварийное завершение — для этой сборки не подтверждена; полноценный kill switch не заявляется. Проверки реального ядра без TUN и безопасного протокола Zapret не заменяют эту приёмку или проверку настоящего сетевого Zapret с UAC.

Доступ к музыке зависит от аккаунта, сервиса и сети. Код Capri — MIT, изображения персонажа исключены из этой лицензии; Mihomo распространяется отдельно по GPLv3 с исходниками и уведомлениями. Автор исходного Capri Desktop — [mochiiwuff](https://github.com/mochiiwuff/capri-desktop).
