# Игровой режим · 0.6.13

В 0.6.13 скрытие действует только на мониторе с активной игрой. На другом мониторе Capri остаётся видимой. Звуки персонажа во время игры подавляются на обоих экранах. Ctrl+Alt+C временно показывает Capri даже поверх игры; повторное нажатие снова включает скрытие. Это исключение сбрасывается при переходе к обычному окну.

Когда активное окно распознано как игра или полноэкранное приложение на мониторе Capri, она скрывает персонажа и быстрое меню и перестаёт перехватывать мышь. При возврате к обычному окну персонаж появляется без перехвата фокуса. Автоматические переходы не переписывают сохранённые громкость, «без звука», видимость и ручной сон. Явный вызов Ctrl+Alt+C возвращает скрытого персонажа. Музыка, которую пользователь включил во встроенном плеере, продолжает играть: игровой режим глушит звуки самого персонажа.

Обычные реплики и жесты во время игры отбрасываются. Вопрос Codex продолжает учитываться: если он ещё ждёт ответа, Capri покажет его после игры без повторного звукового сигнала; если ответ уже дан, старый вопрос не возвращается.

## Распознавание

Существующий непривилегированный наблюдатель Windows проверяет только активное окно:

- геометрию относительно полной области монитора — для полноэкранного и безрамочного режима;
- состояние exclusive Direct3D через [SHQueryUserNotificationState](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shqueryusernotificationstate), значение [QUNS_RUNNING_D3D_FULL_SCREEN](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ne-shellapi-query_user_notification_state);
- известные игровые процессы (включая Roblox, Dota 2, Cyberpunk 2077, Baldur’s Gate 3, War Thunder), игровые окна Unity/Unreal, Minecraft Java и игры из `steamapps/common`.

Обычное развёрнутое окно браузера, Discord и Steam-клиент не считаются игрой. Неизвестная оконная игра вне распознаваемых процессов/движков/Steam может не определиться; её полноэкранный режим определяется по геометрии. Изменений Windows Game Mode, драйверов и внедрения кода в игру нет. Полные пути и названия чужих окон не передаются в renderer и не сохраняются.

## Что проверено

- `scripts/test-game-mode.cjs`: политика распознавания, повторные события, скрытие, временный mute и восстановление без изменения предпочтений.
- `tools/test-game-mode-ui.cjs`: настоящие Electron BrowserWindow/WebContents/IPC с тестовыми снимками наблюдателя; скрытие, звук, закрытие меню, сохранение ручного сна и предпочтений, перезагрузка renderer во время игры.
- `tools/test-game-window-native.cjs`: компиляция native и PowerShell fallback с общим C#-детектором; настоящие скрытые WinForms HWND, оконная/полноэкранная геометрия, имя процесса, исключение собственных и отсутствующих окон. Desktop focus не меняется.
- Проверки новых реакций отдельно описаны в [COMPANION-REACTIONS.md](COMPANION-REACTIONS.md).

Настоящие игры и exclusive DirectX этими тестами не запускаются. Полная связка foreground WinEvent → игра → Electron, Alt+Tab и несколько мониторов требует ручной проверки.

## Ручная проверка на Windows

1. Запусти оконную распознаваемую игру: персонаж и его звуки должны исчезнуть при фокусе на игре.
2. Повтори в безрамочном и exclusive fullscreen. Меню Capri не должно оставаться поверх игры.
3. Переключись Alt+Tab на браузер или Проводник и обратно: Capri возвращается и снова скрывается, не забирая фокус.
4. Закрой/сверни игру, проверь несколько мониторов и разные масштабы Windows.
5. Повтори с ручным сном, скрытым персонажем и выключенными звуками. Сохранённые настройки должны остаться прежними.
6. Задай вопрос Codex во время игры, затем ответь на него до выхода: старое сообщение не должно всплыть после игры. Неотвеченный вопрос должен появиться тихо.
