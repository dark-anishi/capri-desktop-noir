# Capri VPN

The VPN tab is built with Capri's own Electron/JavaScript UI. It does not embed Clash Verge Rev, an iframe or a VPN web dashboard.

1. Import a Mihomo/Clash YAML file, or open VPN → «Профили и подписки» → «Добавить HTTPS-подписку», enter a name and paste the subscription URL, then click «Импортировать подписку». Capri requests the configuration as Mihomo, so services that choose a format by client identity can return compatible YAML automatically. A bare `vless://` URI or a base64 list of share links is not a Mihomo YAML profile and is rejected with a visible message.
2. Select the active profile. The core validates it before storage/application. Subscription-controlled controller, secret, ports, TUN and DNS settings are not imported; local Capri settings own them. Local provider paths and external executable plugins are rejected. HTTPS proxy/rule providers are supported with generated private paths under the core's owned directory.
3. With TUN off, Connect starts a local HTTP/SOCKS proxy on the displayed loopback port. If the saved port is already occupied or reserved by Windows, Capri selects and saves a free port, updates the displayed address and port setting, and records the change in diagnostics. It does not stop the conflicting application. This does not automatically proxy the entire system: configure an application to use the displayed endpoint, or enable TUN.
4. For system TUN, open «Служба и диагностика» → «Установить / обновить службу» and approve Windows UAC for the small native helper. Repeat this once after upgrading from 0.5.2 or earlier to replace the component that crashed at service startup. The Electron application stays unprivileged. Enable TUN and connect. Service control is restricted to the installing Windows account and administrators. Failures distinguish actual UAC cancellation from SCM timeout, access denial and a missing service.
5. Select a server within a Selector group. Click ☆ beside the selected location to save it; ★ removes it. «★ Избранные» filters the selectors, and saved locations also appear at the top under «Избранные». Favorites persist separately for each profile, including across app restarts. Automatic URLTest/Fallback groups remain managed by Mihomo. Ping measures a fixed HTTPS test destination through the selected proxy. Throughput/totals come from the real core's connection counters, not simulated values.
6. Configure DNS, route mode/rules, TUN stack, MTU, IPv4/IPv6 CIDRs and exclusions in the corresponding sections. Apply validates before restarting; a failed apply restores the prior stored state and attempts to restart it. Subscription updates keep a previous version for rollback.
7. In «Сайты без VPN», enter domains or HTTP/HTTPS URLs, one per line, then click «Сохранить исключения». URLs are reduced to their host, duplicate hosts are removed, and subdomains are included. A URL path or port does not limit the exception. IDN domains and IP literals are accepted; rule syntax, credentials and non-HTTP schemes are rejected. Traffic to these hosts goes directly through the normal Internet connection rather than the selected proxy. The empty list preserves existing behavior. Clearing and saving removes all exceptions. Settings persist across restarts and subscription updates. For the Music site, its login, static assets and media may use additional domains, so excluding only the page hostname may be insufficient.

Exceptions precede custom/profile rules in rule mode. Global mode with exceptions runs Mihomo's rule engine with the direct exceptions followed by `MATCH,GLOBAL`, keeping the selected GLOBAL proxy for all other traffic. Native global mode is retained when the exception list is empty; direct mode remains entirely direct. A separate VPN outside Capri can still intercept this direct traffic. These rules do not guarantee website availability or recovery from an ISP/DNS restriction.

Profiles, subscription URLs and proxy credentials are stored with Windows DPAPI through Electron safeStorage. The renderer sees profile metadata only. Runtime configuration files must be readable by the core while it runs: proxy-mode files inherit the current user's AppData permissions and are deleted at stop; service-mode files are in a SYSTEM/Administrators-only ProgramData directory. Do not copy these runtime files into support reports.

The core/helper are fixed-version components, verified by SHA-256. They live outside ASAR. In service mode, installed executables are in a protected Program Files directory. The authenticated pipe client checks the server PID against SCM. Mihomo's REST controller binds to 127.0.0.1 with a fresh random secret. For the privileged core, that secret stays entirely inside the service; even the main process only uses the service's restricted command proxy. Neither the renderer nor the named-pipe client receives the privileged controller secret. Core upgrade/reload and arbitrary REST forwarding are not exposed.

Disconnect disables the owned TUN before core termination. Windows Job Objects own child processes. The service also expires the owner's lease after 30 seconds without a heartbeat, avoiding a permanently abandoned core after an application crash. Recovery is not a verified kill switch. Administrator route/DNS/sleep/failure behavior must be checked with WINDOWS-TUN-TESTS.md before relying on this build for system-wide privacy.

The service is single-owner. Its installation and removal require Windows UAC. Upgrades do not silently replace an installed privileged component; use Install/repair to deploy the currently verified core/helper. Removing Capri invokes the native service removal hook when a service exists. Declining that UAC request aborts uninstall.
