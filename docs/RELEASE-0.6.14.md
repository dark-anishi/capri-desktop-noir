# Capri Desktop NOIR 0.6.14

- Захват указателя при нажатии на персонажа: анимация больше не переключает окно в пропуск кликов до начала перетаскивания.
- Обработка ЛКМ и средней кнопки через Pointer Events; совместимые события мыши не дублируют действия.
- Освобождение нажатия при потере захвата, отмене, потере фокуса и обнаружении отпущенной кнопки.

Проверены регрессии обработки указателя и 12 повторных циклов перетаскивания, ЛКМ и средней кнопки в Electron/WebGL. Длительное использование установленной версии требует проверки пользователем.
