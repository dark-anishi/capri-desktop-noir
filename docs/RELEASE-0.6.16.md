# Capri Desktop NOIR 0.6.16

- Отдельная реакция на отключение и включение экрана Windows без сна ПК: наблюдатель регистрирует `GUID_SESSION_DISPLAY_STATUS` для окна Capri, main process обрабатывает `WM_POWERBROADCAST / PBT_POWERSETTINGCHANGE`.
- Через 250 и 1500 мс выполняется обновление поверхности окна: ширина временно уменьшается на один пиксель и сразу восстанавливается. Это принуждает нативное обновление, которое раньше пользователь вызывал переносом между мониторами.
- Отменяется незавершённое нажатие, снимается захват указателя и повторно проверяется положение курсора. Игровое скрытие сохраняется, окно не активируется. VPN не перезапускается от одного включения экрана.
- Регистрация и отписка реализованы как в нативном наблюдателе, так и в PowerShell fallback. Таймеры и обработчики освобождаются при закрытии.

Проверены настоящая регистрация Windows-уведомлений для Electron HWND из другого процесса, тестовые сообщения off/on без `resume`, восстановление ввода и закрытие окна. Физическое отключение монитора не выполнялось. Нужна ручная проверка: оставить компьютер работающим до автоматического гашения экрана, включить экран движением мыши и проверить ЛКМ, перетаскивание и среднюю кнопку без переноса Capri на другой монитор.

Источники: [уведомления Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerpowersettingnotification), [состояние экрана пользовательской сессии](https://learn.microsoft.com/en-us/windows/win32/power/power-setting-guids), [события Electron powerMonitor](https://www.electronjs.org/docs/latest/api/power-monitor/).
