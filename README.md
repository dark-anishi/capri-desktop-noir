# Capri Desktop · NOIR

**0.6.11 · Windows 10/11 x64 · Electron + JavaScript**

Capri живёт на рабочем столе: сидит на краю окна, болтает ногами, дремлет, реагирует на музыку и сообщает, когда Codex работает или ждёт ответа. В чёрно-белом интерфейсе собраны приложения, папки, Яндекс Музыка и управление VPN и Zapret.

Это самостоятельное развитие [Capri Desktop от mochiiwuff](https://github.com/mochiiwuff/capri-desktop). Авторство, происхождение проекта и исключения из лицензии сохранены в [разделе об авторах](#авторы-и-лицензии).

## Всё под рукой

![Приложения Capri 0.6.11: оригинальные значки и компактные категории](docs/screenshots/0.6.11/apps.jpg)

- **Приложения.** Перетаскивай `.lnk` и `.url` в категории или прямо на Capri. Она предложит категорию; после подтверждения ярлык с рабочего стола переедет в библиотеку. Само приложение останется на месте. Порядок значков сохраняется, а последние запуски игр и остальных приложений показаны отдельно.
- **Папки.** Отдельная вкладка принимает каталоги и ярлыки папок, открывает их в Проводнике и запоминает порядок. Удаление из меню убирает только ссылку; содержимое папок остаётся на месте.
- **Музыка.** Яндекс Музыка открывается внутри Capri с чёрно-белым оформлением. Управление плеером доступно в быстром меню; персонаж реагирует на воспроизведение.
- **Персонаж.** Скины NOIR и ORIGINAL, сидячие позы, сон лёжа с Zzz, реакции на курсор, музыку и события Codex. Реплика сидящего персонажа появляется сбоку.
- **VPN.** Собственный интерфейс для Mihomo: профили, HTTPS-подписки, серверы, избранное, задержки, трафик, DNS, маршрутизация и системный TUN через отдельную Windows-службу.
- **Zapret.** Запуск и остановка выбранной стратегии из твоей локальной папки с сохранением последнего успешно запущенного `.bat`.

## Управление

| Действие | Результат |
| --- | --- |
| Правая кнопка по Capri | Основное окно: приложения, папки, музыка, VPN и скины |
| Средняя кнопка / нажатие колёсика | Быстрое меню у курсора; повторное нажатие закрывает его |
| Левая кнопка | Взаимодействие с персонажем и состояние работы |
| Перетаскивание Capri | Перемещение; на подходящем верхнем краю окна она садится |
| Ярлык, перетащенный на персонажа | Выбор категории перед добавлением |
| `Ctrl+Alt+C` | Спрятать Capri в маленькую иконку / вернуть её |
| Шестерёнка или значок в трее | Настройки, язык, звуки, автозапуск и подключение Codex |

Большое окно можно свернуть; оно отображается в панели задач. В быстром меню есть **Подремать / Проснуться** и **Остаться здесь / Открепить от окна**. Высота подстраивается под содержимое, длинные списки прокручиваются внутри своих разделов.

## VPN внутри Capri

![VPN Capri 0.6.11](docs/screenshots/0.6.11/vpn.jpg)

Импортируй YAML или HTTPS-подписку во вкладке **VPN**, выбери профиль и сервер. Поддерживаемые протоколы определяет включённый Mihomo: в том числе VLESS + Reality, VMess, Trojan, Shadowsocks и Hysteria2. Для избранных локаций используй **☆** рядом с сервером.

**Без TUN** Capri предоставляет локальный HTTP/SOCKS-прокси и не меняет системный прокси Windows. **Для системного TUN** установи или обнови службу из раздела **Служба и диагностика** и подтверди UAC. Сам Electron работает без повышения прав. В **Сайты без VPN** можно добавить домены для прямого подключения.

VPN и Zapret управляются независимо. При смене локации Capri переподключает открытые соединения своего ядра через новый сервер; приложения могут заметить краткий разрыв сетевых сессий.

Полная матрица системного TUN — DNS-утечки, маршруты, сон, смена сети и аварийное завершение — **не подтверждена для этой сборки**. Проверки реального ядра без TUN не заменяют такую приёмку; полноценный kill switch не заявляется. Подробнее: [VPN](docs/vpn/USAGE.md), [отчёт о проверках](docs/vpn/TEST-REPORT.md), [ручные сценарии Windows TUN](docs/vpn/WINDOWS-TUN-TESTS.md).

## Музыка и скины

![Яндекс Музыка во встроенной вкладке Capri 0.6.11](docs/screenshots/0.6.11/music.jpg)

Вход выполняется на сайте Яндекса во встроенном плеере; сессия сохраняется отдельно от обычного браузера. Доступность треков зависит от аккаунта, сервиса и сети. Кнопки предыдущего и следующего трека используют возможности встроенной страницы; звук из любых сторонних приложений не отслеживается.

Все новые изображения интерфейса и поз персонажа находятся в [галерее 0.6.11](docs/SCREENSHOTS.md). Старые изображения исходного проекта не используются здесь как превью текущей версии.

## Установка и сборка

Для обычного использования нужен **Windows 10/11 x64**. Скачай **`Capri-Setup-0.6.11.exe`** из [Releases](https://github.com/dark-anishi/capri-desktop-noir/releases/latest); рядом публикуется `SHA256SUMS`. Установщик не подписан цифровой подписью. Отдельно устанавливать Clash Verge Rev не требуется.

Zapret не включён в Capri: при первом запуске его пункта выбери свою распакованную папку, затем стратегию. Установка VPN-службы и запуск привилегированных сетевых компонентов могут запрашивать UAC; подтверждение выполняется пользователем в Windows.

### Из исходников

Нужны **Node.js 20+**, npm, Windows x64 и компилятор .NET Framework:
`C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.

Открой PowerShell в корне проекта:

```powershell
git clone https://github.com/dark-anishi/capri-desktop-noir.git
cd capri-desktop-noir
npm ci
npm run vpn:prepare
npm test
npm start
```

`vpn:prepare` получает закреплённую версию Mihomo, проверяет контрольные суммы и собирает нативный Windows-помощник. Выполняй эту подготовку **перед тестами на чистом checkout**. Для разработки используй `npm run dev`.

```powershell
npm run dist
```

Сборка автоматически повторяет `vpn:prepare` и создаёт `dist/Capri-Setup-0.6.11.exe`. Текущие сетевые компоненты и установщик рассчитаны на Windows x64; macOS и Linux для этой версии не прошли проверку.

## Подключение к Codex

Выбери установку хуков в настройках Capri или выполни:

```powershell
npm run hooks:install
```

Установщик сохраняет существующие хуки, создаёт резервную копию и добавляет Capri в `~/.codex/hooks.json` с учётом `CODEX_HOME`. Затем начни новую сессию Codex и разреши хуки в его настройках, если этого требует твоя конфигурация. Удаление: `npm run hooks:uninstall`.

Capri получает события работы, ошибок, завершения, запросов разрешения и вопросов через локальный мост `127.0.0.1`. Вопрос остаётся ожидающим во время независимой работы агента. Без Codex персонаж, библиотека и остальные разделы работают самостоятельно.

## Данные и проверки

Настройки и библиотека хранятся в пользовательской папке данных Capri. Профили VPN и URL подписок защищены через Windows DPAPI / Electron `safeStorage`. Не публикуй свою папку данных, временные конфигурации ядра, ключи и ссылки подписок в issues или скриншотах.

Локальный мост хуков не отправляет события во внешний сервис. Встроенная музыка обращается к Яндексу, подписки — к указанному провайдеру, а сетевой трафик VPN — к выбранным серверам. Состав компонентов, результаты и ограничения проверок собраны в [документации](docs/README.md).
